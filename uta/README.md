# 日々うた · 练唱手帖

访问地址：https://hierarchklay.github.io/uta/

从原来的私有 Sites 验证页同步到 GitHub Pages。访问本站无需 ChatGPT 或 GitHub 登录；Apple Music 完整歌曲播放仍由 Apple 的会员和授权决定。

## 维护与发布

- 此目录就是可直接部署的静态源代码：`index.html`、`styles.css`、`app.js`，无需安装依赖或构建。
- 修改本目录并提交到 `main`，由仓库现有 Pages 发布流程部署。保留仓库其他目录与发布配置。
- 版本 08：逐句歌词与高亮、点句连续唱／单句听／单句循环、假名开关、时间轴微调。继续使用 `/uta/` 相对路径部署。后续修改需要同步更新资源版本号。
- 不复制 Sites 的 `.openai/hosting.json`、部署凭据、用户记录或登录信息。
- 发布功能更新时保留站点所有者已填写的 `musickit-config.json`；本地空模板不能覆盖远程配置。

## 当前功能

- 版本 08 在播放后按真实曲目名称、歌手、时长匹配 LRCLIB 歌词；仅接受 ±2 秒以内的明确版本，无法匹配时保留原有播放与 A/B 练习。日文／罗马字目录差异仅使用明确歌手和歌名别名，不做任意模糊匹配。
- 歌词跟随 MusicKit 实际时间逐句高亮；点击一句从此处连续唱，也可只听这句或循环这句，自动填入原有 A/B 选段以便保存。手动滚动暂停跟随，可点「回到当前句」恢复。
- 歌词可提前／延后 0.2 秒、最多 ±10 秒；偏移绑定官方歌曲链接、实际曲目 ID 和歌词版本。假名偏好与时间偏移保存在 `hibi-uta-lyrics-preferences-v1`，不保存歌词正文，暂不跨设备同步。
- 假名使用 Kuromoji 0.1.2 / IPADIC，在 Web Worker 内自动生成；首次开启按需下载约 18 MB 词典，此后可由浏览器缓存。原文不会发送给词典 CDN。未知词或无法唯一对齐的读音保持原样，自动读音可能不等于原唱的特殊读法。
- 歌词请求失败可重试；只有纯文本时显示原文，不编造逐句时间。返回时间轴也可能有人工标注偏差，可用微调和 A/B 修正。单句终点使用下一条时间标记（包括间奏空行），末句使用真实歌曲结尾，不声称准确标出每个词的演唱终点。
- 练习触及歌曲结尾时，如原本在歌单连续听，自动切换为「这首听一遍」并显示提示，以防 SDK 自动转入下一首。末句循环只在 SDK 的 `PlaybackStates.ended/completed` 确认自然结束时恢复播放；普通暂停不会自行重播。

- Rain（秦 基博）、なんもねえ（忘れらんねえよ）、猫じゃらし（7co）三个官方音源入口，可选 MusicKit v3 或原有官方嵌入播放器。
- MusicKit：网站共享令牌自动读取、本机令牌文件导入／粘贴备用、Apple Music 用户授权、播放／暂停、真实播放时间、进度条与指定秒数跳转。
- 整首听一遍、整首循环、三首歌单连续循环。通过 MusicKit 原生 `setQueue({songs})` 和 `PlayerRepeatMode` 执行，连播不依靠网页计时切歌；页面随当前曲目更新，支持上一首／下一首。
- 专辑链接会先用官方目录 API 找出唯一匹配的单曲，再加入队列，避免把整张专辑误当成一首歌。无法唯一匹配时提示换成单曲分享链接。
- A/B 选段可听一遍后暂停、循环练习并显示完成遍数；可手动调整秒数或 `分:秒`，命名保存、移除及撤销最后一次移除。片段绑定歌曲链接和实际曲目 ID，切歌会清除旧标记，版本不匹配时拒绝套用。
- 片段练习需保持前台；进入后台后退出片段练习并恢复所选的整首播放方式。定位精度由 MusicKit 和浏览器调度决定，不保证音频采样级精度或锁屏片段循环。
- 手机底部常驻播放／暂停、后退 5 秒；专注模式收起歌单与辅助内容。测试表和进度诊断默认折叠。
- 两种播放器不会同时播放，测试报告按播放器区分；保留此前的嵌入播放记录。
- 默认中国大陆曲库，可切换地区或填写官方歌曲分享链接。
- 播放器外的官网与歌曲直接链接、Safari 手动复制备用方式。
- 播放、锁屏及锁屏控制结果由用户手动记录，仅保存在当前浏览器，可复制汇总。
- 练习片段和听歌偏好保存在独立的 `hibi-uta-practice-v1`，不包含令牌或音频，暂不跨设备同步。存储失败时明确提示仅当前页面保留。

## MusicKit 接入与实机验证

版本 05 读取 MusicKit v3 的 `currentPlaybackTime`、`currentPlaybackDuration` 和播放事件，通过 `seekToTime()` 跳转。页面轮询只读取 SDK 的实际位置，不推进独立时钟。曲目通过官方 `setQueue()` 加载，普通播放保留整首能力。

### 一次配置，多端使用

1. 在 Mac 打开 [共享配置编辑页](https://github.com/HierarchKlay/HierarchKlay.github.io/edit/main/uta/musickit-config.json)。
2. 把已生成的开发者令牌完整粘贴到 `developerToken` 的双引号内，保持 JSON 格式，提交到 `main`。初始配置为空，须完成这一步才会生效。
3. 等 Pages 发布完成，Mac 和 iPhone 刷新本站，会自动读取同一枚令牌。Apple Music 会员授权仍需每台设备／浏览器分别完成，由 MusicKit 管理，不能把 Music User Token 跨设备共享。

开发者令牌是随网页下发的公开配置，访问者可见。仅在此文件放置为本站生成的开发者令牌，保留 Origin 限制和有限有效期；**不要放入 `.p8` 私钥或 Music User Token**。到期前在同一文件更新，设备刷新后获取新值。当前没有服务端自动签发／续期。

网站每次刷新后首次进入 MusicKit 模式时优先检查共享配置；成功连接后不再使用旧的本地开发者令牌。配置读取使用 `cache: no-store`，最多等待 8 秒；不可用或过期时可退回有效的本机令牌，并显示来源。Pages/CDN 发布仍可能需要时间。手动导入仅影响当前浏览器，不会自动写入 GitHub。共享模式下“重置本机授权”只重置当前设备，再次载入仍使用网站配置。

本机导入备用：在 Mac 的文件选择窗口按 Command + Shift + G，输入 `~/Library/Application Support/Hibi Uta/`，选择生成的令牌 `.txt`。本地校验格式、到期时间及 Origin，不等同于 Apple 的签名验证或会员验证。

先用猫じゃらし验证授权、超过 30 秒播放、进度随播放变化且暂停时停止、前后跳转、前台 A/B 循环，再关闭循环测试锁屏与锁屏控件。之前的嵌入播放通过不代表 MusicKit 已通过。

## MusicKit 令牌准备

## 歌词、读音与功能边界

伴奏、词义和语法仍未接入。公开 MusicKit API 仅用于原唱播放与歌曲元数据；未使用 Apple 私有歌词接口或第三方特权令牌。

歌词只在浏览器运行时从 LRCLIB 的公开 API 获取，保留本次页面内存缓存，不写入本仓库、localStorage、练习记录或测试快照。不下载或转存音频。请求包含应用标识 `Lrclib-Client`，不携带 Apple 令牌，18 秒总超时，顺序请求且最多 3 次；用户切歌会取消旧请求。歌词的文本均通过 DOM 文本节点显示。

LRCLIB 开放的是 API 访问；其 [API 条款](https://lrclib.net/developers/terms) 第 3 条不授予底层歌词版权。不能把社区数据库或开源代码许可表述为歌词展示、处理或再发布权已经取得。Apple Developer 会员同样不代表取得歌词展示／同步许可；公开商业发布或扩展受众前，仍需核对 [MusicKit 内容使用约定](https://developer.apple.com/support/terms/apple-developer-program-license-agreement/) 以及相应歌词权利。本实现不声称完成这些权利清理。
